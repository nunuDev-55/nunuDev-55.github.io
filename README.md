- **nsERP**: sistema de gestão empresarial (projeto de monografia) com vendas, reservas, orçamentos, facturação, stock, pagamentos M-Pesa e loja online.

## Funcionalidades do site

- Modo claro e escuro
- Português e inglês
- Cenas 3D com Three.js e shaders WebGL
- Animações ligadas à rolagem (GSAP + ScrollTrigger) e rolagem suave (Lenis)
- Paleta de comandos (Ctrl/⌘ + K)
- Formulário que prepara a mensagem no WhatsApp
- Currículo em PDF

## Tecnologias

HTML, CSS, JavaScript, GLSL, Three.js, GSAP, Lenis.

Site estático: não precisa de build nem de servidor. Basta abrir o `index.html`.
